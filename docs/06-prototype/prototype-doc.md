# UK Rental Map - 原型设计文档

## 1. 页面总览

| 编号 | 页面名称 | 页面类型 | 布局 | 对应PRD |
|------|----------|----------|------|---------|
| P01 | 首页/地图浏览 | 核心页 | 左侧筛选面板(280px) + 右侧全屏地图 + 左下房源列表 | F1-F3 |
| P02 | 标注弹窗 | 地图Popup | 地图上的信息弹窗卡片(320px) | F4 |
| P03 | 房源详情页 | 内容页 | 左栏信息(flex) + 右栏评价(340px) | F4,F7 |
| P04 | 登录/注册 | 模态卡片 | 居中卡片(400px) | F5 |
| P05 | 发布出租信息 | 表单页 | 左栏表单(flex) + 右栏地图定位(340px) | F8 |
| P06 | 发布评价 | 模态卡片 | 居中卡片(500px) | F6 |
| P07 | 管理后台 | 后台页 | 左侧菜单(200px) + 右侧内容区 | F9,F10 |

**全部Web桌面端 · 1200px宽度**

## 2. 导航关系

```
P01 首页（左侧筛选 + 右侧地图 + 左下房源列表）
  ├── 点击地图标注 → P02 信息弹窗（Popup）
  │                    └── "查看详情" → P03 房源详情页
  │                                      └── "留评价" → P06
  ├── 导航栏"发布出租" → (需登录→P04) → P05
  ├── 导航栏"留评价" → (需登录→P04) → P06
  ├── 导航栏"登录/注册" → P04
  └── /admin → P07 管理后台
```
